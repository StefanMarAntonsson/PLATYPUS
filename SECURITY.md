# Security Policy

## Supported versions

Security fixes are provided for the latest released version of PLATYPUS. Please update to the
latest release before reporting an issue that may already have been resolved.

## Reporting a vulnerability

Please report suspected security vulnerabilities through GitHub Private Vulnerability Reporting:

1. Open the PLATYPUS repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected version, steps to reproduce the issue, its potential impact, and any proposed
fix or mitigation you have identified. Please do not disclose the vulnerability in a public issue
or discussion before it has been investigated and resolved.

Reports will be reviewed through GitHub's private security-advisory workflow. Updates and any
requests for additional information will be provided in that private report.
